# Employee Data Management & Analytics Dashboard

## 📌 Project Overview
An Excel-based Employee Data Management and Analytics Dashboard developed to organize employee records, analyze workforce data, and generate meaningful reports using Excel.

## 📊 Dataset
- **Total Records:** 461 employees
- **Departments:** 8
- **Cities:** 8
- **Attributes:** Employee ID, Employee Name, Department, City, Salary, Joining Date
- **Dataset Type:** Synthetic data created for educational purposes.

## 🛠️ Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Data Visualization

## 📈 Key Performance Indicators (KPIs)
- Total Employees
- Average Salary
- Highest Salary

## 📉 Dashboard Visualizations
1. **Average Salary by Department:** Compares average salaries across different departments.
2. **Employee Distribution by City:** Displays employee distribution across different cities.
3. **Employee Joining Trends by Year:** Analyzes employee joining patterns over time.

## ✨ Key Features
- Employee data organization and management.
- Department-wise employee and salary analysis.
- City-wise employee distribution.
- Year-wise joining trend analysis.
- KPI-based reporting dashboard.
